# 📚 Estudos de Kotlin

Este repositório foi criado para registrar minha evolução nos estudos de **Kotlin**, como parte do meu aprendizado em **Programação Orientada a Objetos (POO)**.

Estou utilizando este espaço para guardar exercícios, testes e exemplos desenvolvidos durante meus estudos, colocando em prática os conceitos que venho aprendendo.

### 🧠 Conteúdos estudados até o momento

* Variáveis e tipos de dados;
* Estruturas condicionais:

  * `if`
  * `else`
* Estruturas de repetição;
* `forEach`;
* Coleções em Kotlin;
* Arrays e manipulação de dados.

### 🎯 Objetivo

Meu objetivo é construir uma base sólida em Kotlin e, gradualmente, avançar para os conceitos de **Programação Orientada a Objetos**, aplicando o conhecimento adquirido em exercícios e pequenos projetos.

Este repositório será atualizado conforme eu avançar nos estudos e aprender novos conceitos.

> 🚀 **Em constante aprendizado e evolução na programação.**
